# НутриГайд — Интерактивный путеводитель по БАДам и витаминам

> Современное интерактивное веб-приложение в стиле **Liquid Glassmorphism** для структурированного изучения биологически активных добавок, витаминов и персонального подбора на основе тестирования.

## Ключевые возможности

- **Научный каталог БАДов:** 17 ключевых добавок и витаминов (Витамины D3, A, C, E, Кальций, Цинк, Железо, Магний, BCAA, Креатин, L-Цитруллин, ГАМК, Мелатонин, Коллаген, Хлорофилл, Омега-3, Коэнзим Q10).
- **22 реальных препарата:** оригинальные фотографии и подробные составы (NOW Foods, Solgar, Doppelherz, Эвалар, California Gold Nutrition, Doctor's Best и др.).
- **Стеклянный премиальный дизайн (Glassmorphism):** полупрозрачность, размытие фона, мягкое неоновое свечение, полная адаптивность для мобильных телефонов и компьютеров.
- **Векторная графика:** интерфейс построен строго на чистых SVG-иконках без использования смайликов и эмодзи.
- **Интерактивный опросник (Скрининг):** 10 вопросов для определения дефицитов рациона, уровня стресса, физической активности и индивидуальных целей.
- **Умный алгоритм рекомендаций:** выдача персонального плана БАДов, таймлайн безопасного распределения приёма (Утро / День / Вечер) и учет медицинских противопоказаний.
