# Код Добавки — Научный путеводитель по БАДам и витаминам

> Интерактивный путеводитель по биологически активным добавкам и витаминам в светлом эко-дизайне (**Botanical Organic Glassmorphism**).

## Особенности проекта

- **Логотип и фирменный стиль:** проект «Код Добавки» выполнен в эстетичной светло-зеленой гамме (шалфей, мята, свежий изумруд, белый матовый глянец).
- **Горизонтальная витрина-карусель:** без бесконечных простыней текста — удобное перелистывание карточек препаратов свайпом, кнопками и точками-индикаторами.
- **17 научно обоснованных БАДов:** Витамины D3, A, C, E, Кальций, Цинк, Железо, Магний, BCAA, Креатин, L-Цитруллин, ГАМК, Мелатонин, Коллаген, Хлорофилл, Омега-3, Коэнзим Q10.
- **22 оригинальных препарата из файла:** NOW Foods, Solgar, Doppelherz, Эвалар, California Gold Nutrition, Doctor's Best и др.
- **Модальное окно с фото-каруселью:** полноразмерный просмотр упаковок с мгновенным закрытием по крестику или по фону.
- **Интерактивный опросник из 10 шагов:** скрининг дефицитов рациона, стресса, сна и спортивной активности.
- **Персональный график приёма:** безопасное разделение на Утро, День и Вечер с учетом совместимости элементов.
